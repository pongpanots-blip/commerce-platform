แนวทางปฏิบัติงานและการจัดการราคาสินค้า (Pricing Operations Protocol)
1. การรับข้อมูลราคาจาก ERP

เมื่อฝ่าย Merchandiser หรือ Procurement อัปเดตราคาใน SAP ข้อมูลจะถูกดึงเข้าคิวรออนุมัติโดยอัตโนมัติ พร้อมแสดงผลต่างราคาและเงื่อนไข MOQ

2. การตรวจสอบและอนุมัติ (MER)

เจ้าหน้าที่ MER ตรวจสอบความถูกต้องของราคาขายต่อหน่วยและราคาสั่ง หากพบความผิดปกติสามารถกดปุ่ม "แก้" เพื่อปรับปรุงก่อนส่งมอบ

3. การซิงค์ไปยังร้านค้า (josh)

ทันทีที่กดอนุมัติ ระบบจะล้าง cache ราคาและส่ง payload ไปยัง storefront service (josh) ทันที มีผลต่อการคำนวณราคาทุกช่องทางจำหน่าย
