แนวทางปฏิบัติงานและการผูกสื่อสินค้า (Product Media Guidelines)
1. ลำดับการแสดงผลวิดีโอ
ระบบ Commerce กำหนดให้วิดีโอถูกจัดวางต่อจากภาพนิ่งเสมอ เพื่อให้ลูกค้าได้ดูมุมมองหลักของสินค้าก่อนชมคลิปสาธิต
2. การผูกหลาย SKU พร้อมกัน
กรณีวิดีโอชุดเดียวกันใช้กับสินค้ากลุ่มเดียวกัน (เช่น สีหรือขนาดต่างกัน) สามารถเลือกหลาย SKU เพื่อประหยัดพื้นที่จัดเก็บและลดเวลาอัปโหลด
3. การแปลงไฟล์และ CDN
หลังการอัปโหลด ระบบเบื้องหลังจะสร้างไฟล์ Adaptive Bitrate Streaming สำหรับทั้งแอปพลิเคชันมือถือและเดสก์ท็อปโดยอัตโนมัติ
