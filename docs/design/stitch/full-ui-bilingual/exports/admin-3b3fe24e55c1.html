ข้อกำหนดระบบหน้าร้าน

  • check_box
    ข้าม (audience ว่าง):

    หาก Audience ไม่ได้ถูกเซ็ตบนระบบ ระบบจะไม่ยิง offer ไปยังหน้าร้าน

  • check_box
    การประเมิน Fallback:

    กรณีไม่มีหัวข้อ จะแสดงแท็ก (ไม่มี title)

  • check_box
    พฤติกรรม Popup ร้านค้า:

    ว่าง = shop ไม่เด้ง (มักเพราะทุก offer เป็น dismissed หรือยังไม่ลิงก์ user)

หน้านี้สร้างก่อนมี Campaign และเปิดตลอด — ผูกแล้วหน้าจะแสดงสินค้าของโปรอัตโนมัติ + คูปองสาธารณะของ campaign นั้นเท่านั้น (ไม่ใช่ mechanic เดิม) วันที่ใช้ของ campaign และย้อนกลับจากหน้า admin ไม่ได้ (ระบบจะถามยืนยันก่อนบันทึก)
