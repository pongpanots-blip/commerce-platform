เพิ่ม Supplier

บันทึกข้อมูลซัพพลายเออร์ คู่ค้า ผู้ติดต่อ ช่องทางจัดส่ง และเงื่อนไขการสั่งซื้อเข้าระบบ

บันทึกแบบร่างอัตโนมัติเมื่อสักครู่
info

การเชื่อมต่อระบบบัญชีและ ERP

ยืนยันแล้ว

ข้อมูลรหัส Supplier (SUP Code) และเลขประจำตัวผู้เสียภาษีจะถูกซิงก์โดยอัตโนมัติไปยังระบบคลัง Inbound Logistics และระบบจัดซื้อกลาง เมื่อสร้างเสร็จสมบูรณ์ คุณสามารถผูกสินค้าเข้ากับซัพพลายเออร์นี้ได้ทันที

error
เกิดข้อผิดพลาดในการบันทึก: กรุณากรอกชื่อ Supplier และข้อมูลติดต่อหลักให้ครบถ้วนก่อนส่งข้อมูล
