ข้อกำหนดการจัดการสินค้าและกฎการเชื่อมต่อระบบ (Product Management Protocol)

1. กฎการอนุมัติการอัปเดตจาก ERP

เมื่อ ERP มีการส่งการเปลี่ยนแปลงข้อมูลมา เช่น ปรับราคา หรือเปลี่ยนชื่อสินค้า ระบบจะกักไว้ในสถานะ "รออนุมัติ ERP" เพื่อให้ทีมงานตรวจสอบก่อนส่งไปยัง Storefront

2. การสร้างและแก้ไขสินค้า

รหัส SKU จะต้องไม่ซ้ำกันในระบบ การสร้างสินค้าใหม่สามารถระบุชื่อ หมวดหมู่ และรายละเอียดเริ่มต้นได้ โดยราคาขายและสต็อกสามารถเชื่อมโยงตามลำดับ

3. ขอบเขต API และการค้นหา

การค้นหาในตารางเป็นการกรองข้อมูลเฉพาะหน้านี้ตามข้อกำหนด Pagination API เพื่อประสิทธิภาพสูงสุดของระบบหลังบ้าน
