policy เกณฑ์การกันสต็อกอัตโนมัติ (Inventory Hold Policies)

การกันสต็อก (Hold) เกิดขึ้นทันทีในขั้นตอน Checkout ของลูกค้า โดยมีกำหนดเวลา Hold สูงสุด 24 ชั่วโมง เพื่อรอการยืนยันการชำระเงิน หากเลยกำหนดระบบจะปลดสต็อกคืนคลังสินค้าอัตโนมัติ

• คลังสินค้าหลัก: WH-BKK01 (บางนา กรุงเทพฯ)
• TTL Timeout: 86400 วินาที (24 ชั่วโมง)
• Concurrency Lock: Redis Mutex Token
