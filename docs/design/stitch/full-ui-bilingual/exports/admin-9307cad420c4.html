คำแนะนำและข้อกำหนดการทำงานด้านสต็อก (Stock Operations Guide)

1. รับเข้า (Receive)

เพิ่มสินค้าที่ได้รับเข้าในคลัง

ระบุจำนวนที่รับเพิ่ม ระบบจะบวกเข้ากับยอดคงเหลือเดิม

2. ตรวจนับ (Count)

ปรับยอดตามจำนวนที่นับได้จริง

ระบุยอดทั้งหมดที่นับได้ ระบบจะใช้จำนวนนี้แทนยอดคงเหลือเดิม

3. ปรับยอด (Adjust)

บันทึกสินค้าเสียหาย รับคืน หรือแก้ไขยอด

เลือกเหตุผลก่อนกรอกจำนวน: เสียหายจะลดยอด รับคืนจะเพิ่มยอด

4. โอนย้าย (Transfer)

ย้ายสินค้าจากคลังหนึ่งไปอีกคลัง

จำนวนนี้จะลดจากคลังต้นทางและเพิ่มในคลังปลายทาง โดยต้องเลือกคนละคลัง
