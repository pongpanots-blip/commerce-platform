info ข้อกำหนดการเชื่อมโยงข้อมูลซัพพลายเออร์ (Supplier Management Protocol)
1. การผูกรหัส Supplier กับ ERP

รหัสคู่ค้า (Vendor Code) จะถูกจับคู่แบบทูเวย์ซิงก์กับ SAP / Josh เพื่อใช้ตรวจสอบยอดรอบส่งสินค้าและออกใบสั่งซื้อ (PO) อัตโนมัติ

2. รอบการสั่งซื้อ Pre-order

เมื่อผูกรอบสั่งซื้อในเมนู /order-periods แล้ว ระบบหน้าบ้านจะคำนวณวันส่งมอบสินค้าและเวลาปิดรับออเดอร์ให้ลูกค้าโดยอัตโนมัติ

3. ข้อมูลผู้ติดต่อและการแจ้งเตือน

อีเมลและเบอร์โทรที่ระบุจะได้รับเอกสารใบสรุปยอดรับสินค้า (Goods Receipt) ทันทีที่ฝ่ายคลังบันทึกความเคลื่อนไหวสต็อกสำเร็จ
