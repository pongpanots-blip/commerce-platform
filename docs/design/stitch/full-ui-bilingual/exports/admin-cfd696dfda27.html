ข้อกำหนดการทดสอบจำลอง ERP Stub (Sandbox Protocol)

แนวทางการทำงานและผลกระทบของข้อมูลจำลองในส่วน on_hand fulfillment

1. ขอบเขตการทำงานของ Stub

จำลองค่าสต็อก on_hand ของสินค้าแต่ละ SKU เพื่อให้ทีมทดสอบสามารถสั่งซื้อและประมวลผลคำสั่งซื้อได้โดยไม่ติดสถานะสินค้าหมด

2. การซิงค์และบันทึก

เมื่อกด "Set stock" ยอดจะถูกบันทึกลงในฐานข้อมูลจำลองทันที และอัปเดตแคชของระบบ storefront / order service

3. สภาพแวดล้อม Sandbox

การตั้งค่าสต็อกในหน้านี้ไม่มีผลกับระบบ SAP ERP จริงบน Production เหมาะสำหรับการทดสอบ Integration test
