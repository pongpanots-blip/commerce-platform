2 งานบำรุงรักษา

Relink users จาก CSV

อ่าน customer code จากไฟล์ orders แล้วผูก user ใหม่

ผลกระทบ (Consequence):

ระบบจะค้นหา user ID ใหม่ตาม customer_code ในไฟล์ CSV ที่ระบุ และแทนที่ user_id เดิมบนออเดอร์ทันที ออเดอร์ที่เคยผูกกับลูกค้าอื่นจะถูกย้ายมายังบัญชีใหม่

Relink all (จาก customer_code ใน DB)

ไม่ต้องอัปโหลดไฟล์ — ใช้ customer_code ที่บันทึกไว้บน order

ผลกระทบวงกว้าง (System-wide Consequence):

กระบวนการนี้จะวนรอบตรวจ ทุกออเดอร์ในฐานข้อมูลทั้งหมด เพื่อจับคู่ใหม่กับลูกค้าตามรหัสที่บันทึกไว้ งานนี้ใช้ทรัพยากรฐานข้อมูลสูงและไม่สามารถย้อนคืนได้
