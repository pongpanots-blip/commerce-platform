ได้ออกแบบหน้าจอ **"ระบบเชื่อมต่อ — การเชื่อมต่อ"** สำหรับ **Commerce Platform** เรียบร้อยแล้ว โดยรักษาความต่อเนื่องทางสถาปัตยกรรมข้อมูลและภาษาการออกแบบ (Visual Language) ของระบบเดิมอย่างแม่นยำ:

### รายละเอียดการออกแบบและองค์ประกอบสำคัญ:
1. **โครงสร้างและการจัดวาง (Layout & Navigation):**
   - แถบเมนูด้านซ้ายขนาด 256px แสดงครบทั้ง 7 หมวดหมู่งานปฏิบัติการ พร้อมไฮไลต์สถานะการทำงานที่หมวด **"ระบบเชื่อมต่อ"** อย่างชัดเจน พร้อมลิงก์ไปยัง "นักพัฒนา & API" ด้านล่าง
   - ส่วนหัวกระดาน (Contextual Header) พร้อม Breadcrumbs นำทาง และการระบุขอบเขตการค้นหา "ค้นหาเฉพาะข้อมูลในหน้านี้เท่านั้น" ตามข้อกำหนดการใช้งานระบบ

2. **ตารางรายการช่องทางการเชื่อมต่อ (Connections Table):**
   - จัดแสดงรายการข้อมูลมาก่อนแบบฟอร์มการสร้าง ตามหลัก UX การทำงานของทีมปฏิบัติการ
   - คอลัมน์ครบถ้วนตามข้อกำหนด: **ชื่อการเชื่อมต่อ**, **ประเภท**, **สถานะ** (จับคู่สีและข้อความชัดเจน ไม่ใช้สีเพียงอย่างเดียว), **ยืนยันลายเซ็น (Signing)** (แสดงเฉพาะสถานะการเข้ารหัส ไม่เปิดเผยรหัสลับ Signing Secret), และ **Webhook Endpoint URL** พร้อมปุ่ม Copy สำหรับใช้งานจริง
   - ป้ายกำกับ **ข้อมูลตัวอย่าง** กำกับชัดเจนตามเกณฑ์ระบบ

3. **แบนเนอร์แจ้งเตือนสถานะความผิดพลาด (Operational Inset):**
   - กล่องแจ้งเตือนสีเหลือง/ส้มแบบเรียบสงบ แสดงข้อมูลข้อผิดพลาดจริงของระบบภายนอก (เช่น Flash Express HTTP 504 Gateway Timeout พร้อมลิงก์ไปหน้าตรวจสอบรายการส่งไม่สำเร็จ) แทนการแสดงสถานะระบบเขียวสมบูรณ์แบบที่ไม่สมจริง

4. **การเชื่อมโยงงานที่เกี่ยวข้อง (Task-based Navigation):**
   - แท็บและกล่องการ์ดงานด้านล่างเพื่อเข้าถึง **ข้อมูลขาเข้า (Inbound Data)**, **งานซิงก์ข้อมูล (Sync Jobs)**, และ **รายการส่งไม่สำเร็จ (Failed Deliveries)** ได้อย่างรวดเร็ว
