สร้างหน้าจอเดสก์ท็อป **"ลูกค้าและบริการ — ลูกค้าแพลตฟอร์ม"** เรียบร้อยแล้ว โดยรักษาความต่อเนื่องของระบบดีไซน์และโครงสร้าง UI เดิมอย่างเคร่งครัด:

### รายละเอียดการออกแบบและองค์ประกอบสำคัญ:
1. **โครงสร้างและแถบนำทาง (256px Sidebar & Top Bar):**
   - แถบเมนูด้านซ้าย 7 หมวดหมู่งานปฏิบัติการ โดยไฮไลต์หมวด **"ลูกค้าและบริการ"**
   - ส่วนหัวแสดงข้อมูลบริบทพร้อมการค้นหาระบบ และโปรไฟล์เจ้าหน้าที่คลังสินค้า
2. **ส่วนหัวหน้างานและปุ่มปฏิบัติการหลัก (Page Header & Actions):**
   - หัวข้อ `ลูกค้าแพลตฟอร์ม` พร้อมป้ายกำกับ `ข้อมูลตัวอย่าง`
   - ปุ่มหลัก **+ เพิ่มลูกค้า** (`#365cf5`) และปุ่มรอง **รีเฟรช**
3. **ตัวกรองและตารางข้อมูลลูกค้า (Customer Table & In-Page Search):**
   - ช่องค้นหาที่ระบุเจาะจงชัดเจนว่า `ค้นหาในหน้านี้...` พร้อมข้อความกำกับว่าเป็นการค้นหาเฉพาะข้อมูลในหน้านี้ตามขอบเขต API
   - ตัวเลือกสถานะและจำนวนแสดงผลต่อหน้า
   - ตารางแสดงคอลัมน์: **ชื่อลูกค้า / รหัสอ้างอิง**, **อีเมล**, **เบอร์โทรศัพท์**, และ **สถานะบัญชี**
   - ข้อมูลตัวอย่าง 3 รายการสมมติ พร้อมลิงก์ไปยังรายละเอียดลูกค้า
4. **ส่วนงานเชื่อมโยงที่เกี่ยวข้อง (Task Links Card):**
   - การ์ดทางลัดด้านล่างที่สงวนไว้สำหรับงานปฏิบัติการที่เกี่ยวข้อง: ข้อมูลนิติบุคคลและคู่ค้า, ตรวจสอบและยืนยันข้อมูลลูกค้า, และรายการแจ้งเรื่องและบริการลูกค้า
   - ไม่มีองค์ประกอบที่ไม่ได้รับการสนับสนุนจาก API เช่น CRM Analytics หรือปุ่ม Export/Import ที่ไม่ได้ระบุไว้ในข้อกำหนด
