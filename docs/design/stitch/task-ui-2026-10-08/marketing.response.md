ได้สร้างหน้าจอเดสก์ท็อป **"การตลาด — ศูนย์รวมงานปฏิบัติการ"** สำหรับระบบ Commerce Platform เรียบร้อยแล้ว โดยรักษาความต่อเนื่องของ Visual Language และโครงสร้างระบบเดิมไว้อย่างเคร่งครัด:

### รายละเอียดการออกแบบและองค์ประกอบสำคัญ:
1. **โครงสร้างและแถบนำทาง (256px Sidebar & Top Header):**
   - แถบนำทางด้านซ้ายแสดง 7 หมวดหมู่งานปฏิบัติการหลัก โดยเปิดสถานะ Active ไฮไลต์ชัดเจนที่เมนู **"การตลาด"** (ไอคอนโทรโข่ง / campaign) พร้อมลิงก์ไปยัง "นักพัฒนา & API" ด้านล่าง
   - ส่วนหัวด้านบนมีกล่องค้นหาภาพรวมระบบ ข้อมูลผู้ใช้งาน และการแจ้งเตือนสอดคล้องกับหน้าอื่นๆ ในโปรเจกต์
2. **การค้นหาและงานประจำวัน (Search & Frequent Tasks):**
   - ช่องค้นหาเฉพาะหมวด **"ค้นหาในหมวดการตลาด..."** พร้อมคำอธิบายขอบเขตการค้นหา
   - การ์ดงานที่ดำเนินการบ่อย 4 รายการ: *จัดการแคมเปญ*, *สร้างคูปองส่วนลด*, *Template ข้อความ*, และ *คิวงานการตลาด* พร้อมปุ่มลิงก์แอ็กชันที่ชัดเจน
3. **ขั้นตอนแนะนำการวางแผน (Three-step Planning Guide):**
   - ไกด์แนะนำกระบวนการ 3 ขั้นตอน: *กำหนดกลุ่มเป้าหมาย (Segments)* → *เตรียมข้อความและโปรโมชัน (Creative & Offers)* → *เปิดใช้งานและติดตามผล (Launch & Tracking)* ในรูปแบบ Lightweight cards โดยไม่มีการใส่ชาร์ตหรือตัวเลขสมมติที่ขัดกับ API
4. **หมวดงานหลัก 4 ส่วน (Task Sections Grid):**
   - **วางแผนและค้นคว้า:** วางแผนการเติบโต, แผนและปฏิทิน, งานวิจัยตลาด, ค้นหาตลาดร้านอาหาร, ผู้ช่วยวิเคราะห์การตลาด
   - **แคมเปญและโปรโมชัน:** แคมเปญ (Campaigns), คูปอง (Coupons), กลไกโปรโมชัน (Promotion mechanics), กลุ่มลูกค้าเป้าหมาย (Segments)
   - **เนื้อหาและการสื่อสาร:** Template ข้อความ, อีเมลต้อนรับลีด, Marketing links, Smart links, Push campaigns
   - **ติดตามผลและตั้งค่า:** เส้นทางลูกค้า (Journey funnel), สถิติการจัดส่งข้อความ (Notification delivery stats), คิวงานการตลาด, ตั้งค่าการตลาด
5. **ความประณีตตาม Design System:**
   - ใช้งานโทนสี Light canvas `#f6f8fc`, การ์ดสีขาวขอบ `#e1e7f0`, ฟอนต์ Noto Sans Thai, สัดส่วนความกว้างคอนเทนต์ประมาณ 1,240px และแถบสถานะระบบ (Log & API status) ด้านล่างสุดครบถ้วน
