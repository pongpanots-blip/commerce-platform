สร้างหน้าจอเดสก์ท็อป **"รายงานและข้อมูล — ศูนย์รวมรายงานและข้อมูลระบบ"** สำหรับ Commerce Platform เรียบร้อยแล้วครับ

### รายละเอียดการออกแบบและโครงสร้างตามข้อกำหนด:
1. **แถบนำทางหลัก (256px Sidebar):**
   - คงหมวดหมู่งาน 7 ด้านของระบบไว้ครบถ้วน โดยไฮไลต์สถานะ Active อย่างชัดเจนที่หมวด **"รายงานและข้อมูล"** (ไอคอน `bar_chart` พร้อมแถบสี `#365cf5` และสัญลักษณ์สถานะ)
   - ส่วนท้ายระบุลิงก์ "นักพัฒนา & API" และเวอร์ชันระบบตามมาตรฐานเดิม

2. **ส่วนหัวและการค้นหาไดเรกทอรี:**
   - Breadcrumb แสดงลำดับชั้น `หน้าหลัก > รายงานและข้อมูล` พร้อมป้ายกำกับ `ศูนย์รวมงานปฏิบัติการ` และ `ข้อมูลตัวอย่าง`
   - ช่องค้นหาเจาะจงเฉพาะในหน้าไดเรกทอรี พร้อมข้อความอธิบายอย่างสุภาพว่า *การเลือกช่วงเวลาและตัวกรองละเอียดจะทำที่หน้ารายงานจริง*

3. **การ์ดรายงานที่เปิดใช้งานบ่อย (4 คอลัมน์):**
   - รวบรวม 4 รายงานยอดนิยม ได้แก่ *รายงานยอดขาย, รายงานออเดอร์, รายงานสินค้า* และ *การเข้าชมและระบบ* โดยไม่มีการใส่ตัวเลขสถิติหลอกหรือชาร์ตกราฟที่ไม่มี API รองรับ

4. **หมวดหมู่งาน 3 ส่วนหลัก (Task Directory Sections):**
   - **ยอดขายและคำสั่งซื้อ (3 รายการ):** รายงานยอดขาย, รายงานออเดอร์, กลุ่มลูกค้าเป้าหมาย
   - **สินค้า ลูกค้า และราคา (4 รายการ):** รายงานสินค้า, รายงานลูกค้าและบริษัท, รายงานราคาขาย, ราคา: commerce คิดคู่กัน (ทดลอง)
   - **การเข้าชมและสุขภาพระบบ (2 รายการ):** การเข้าชม, สุขภาพระบบ

5. **สไตล์และระบบภาพ (Visual Language):**
   - โทนสี Light canvas (`#f6f8fc`), การ์ดสีขาวขอบเส้นประณีต (`#e1e7f0`), รัศมีมุม 12px และปุ่มควบคุม 8px
   - ฟอนต์ Noto Sans Thai และระยะเว้นวรรค 16/24/32px เข้าชุดกับหน้าจอเดิมอย่างสมบูรณ์แบบครับ
