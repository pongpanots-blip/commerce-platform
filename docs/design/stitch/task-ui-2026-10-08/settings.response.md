ได้สร้างหน้าจอ **"ตั้งค่าและทีมงาน — บัญชีทีมงาน"** เรียบร้อยแล้ว โดยรักษาความต่อเนื่องของดีไซน์ซิสเต็มและข้อกำหนดของ Commerce Platform อย่างครบถ้วน:

### รายละเอียดการออกแบบและฟังก์ชันบนหน้าจอ:
1. **โครงสร้างและแถบนำทาง (Navigation & Layout):**
   - แถบเมนูด้านข้าง (Sidebar) ขนาด 256px แสดงครบทั้ง 7 หมวดหมู่งาน โดยไฮไลต์หมวด **"ตั้งค่าและทีมงาน"** เป็นสถานะเปิดใช้งาน (Active) พร้อมลิงก์เข้าสู่หน้าพอร์ทัล *นักพัฒนา & API*
   - ส่วนหัวด้านบน (Top Bar) แสดง Breadcrumb นำทาง, ช่องค้นหาระบบ และข้อมูลโปรไฟล์ผู้ใช้งานปัจจุบัน (*สมชาย ปฏิบัติการ*)
   - ความกว้างเนื้อหาหลักอยู่ในกรอบ 1240px บนพื้นหลังสี `#f6f8fc` พร้อมการ์ดสีขาวและเส้นขอบ `#e1e7f0`

2. **ส่วนหัวของหน้าและข้อความแนะนำ (Header & Guidance Alert):**
   - หัวข้อหน้า **"บัญชีทีมงาน"** กำกับป้าย `ข้อมูลตัวอย่าง` อย่างชัดเจน
   - ปุ่มหลัก **"+ เพิ่มบัญชี"** (Primary Blue `#365cf5`) และปุ่มเงียบ **"รีเฟรช"**
   - แถบข้อความแนะนำด้านความปลอดภัย ระบุชัดเจนว่าบทบาทควบคุมการเข้าถึง และบัญชีที่สร้างใหม่จะได้รับรหัสผ่านชั่วคราวทางอีเมล โดยไม่มีการแสดงรหัสผ่านบนหน้านี้

3. **แท็บนำทางและตัวกรองข้อมูล (Tabs & Filters):**
   - แท็บย่อย: *บัญชีทีมงาน* (เปิดใช้งาน), *บัญชีทีมงานร้านค้า*, และ *เปลี่ยนรหัสผ่าน*
   - แถบค้นหาระบุขอบเขตการทำงานชัดเจน (*"ค้นหาเฉพาะข้อมูลในหน้านี้เท่านั้น"*) พร้อม Dropdown คัดกรองตามสิทธิ์และสถานะ

4. **ตารางรายชื่อทีมงาน (Staff Accounts Table):**
   - คอลัมน์ครบถ้วน: *อีเมล*, *ชื่อ*, *สิทธิ์*, *สถานะ*, *สร้างเมื่อ*, และ *จัดการ*
   - บัญชีของผู้ใช้งานปัจจุบันทำเครื่องหมาย **"คุณ"** ไฮไลต์ชัดเจน พร้อมล็อกการแก้ไขสิทธิ์/สถานะของตนเอง
   - แสดงสถานะการทำงานด้วยข้อความคู่กับจุดสี (เช่น *ใช้งานปกติ* จุดเขียว `#157347`, *ระงับการใช้งาน* จุดเหลือง/แดง)
   - ปุ่มคำสั่งจัดการตรงตามขอบเขตของระบบจริง: *รีเซ็ตรหัสผ่าน*, *ปิดบัญชี*, และ *เปิดใช้งานบัญชี*

5. **เมนูทางลัดงานที่เกี่ยวข้อง (Related Tasks) และแถบสถานะระบบ (Status Bar):**
   - การ์ดทางลัดสู่การเปลี่ยนรหัสผ่านส่วนตัว, การตรวจสอบรายละเอียดสิทธิ์, และบัญชีทีมงานร้านค้า
   - แถบสถานะส่วนล่างแจ้งเตือนการบันทึก Audit Log ทุกรายการ, Timezone (GMT+7) และความพร้อมใช้งานของ API
